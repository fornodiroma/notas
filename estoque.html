Insumos

Pizzas / produtos e fichas técnicas

Quanto de cada insumo vai em 1 unidade vendida. Bebidas: 1 un do próprio insumo.

Como cada item de NF-e vira um insumo do estoque. Identifique por CNPJ+código do fornecedor, código de barras (EAN) ou um trecho da descrição. Fator = quantas g/ml/un há em 1 unidade comercial da nota (caixa, saco, balde...); deixe vazio quando a nota vem em KG, G, L, ML ou UN.

Gravação no GitHub

Para salvar direto no repositório, crie um token em GitHub → Settings → Developer settings → Fine-grained tokens: só para o repositório , permissão Contents: Read and write, validade de até 90 dias. O token fica só neste aparelho (nunca vai para o repositório); sem "lembrar", some ao fechar o navegador. Antes de emprestar o aparelho, use Esquecer token.

Lojas (CNPJ do destinatário das NF-es)

Opcional. Com as lojas cadastradas, a conciliação pode ser filtrada por loja: a NF-e entra na loja do CNPJ de destino; vendas e contagens têm o campo loja.

Fornecedores fora do estoque

Notas destes fornecedores (equipamentos, serviços, manutenção...) não entram na conciliação. Marque pela aba NF-es ("Ignorar este fornecedor").

Arquivos

Os dados ficam em dados/estoque/: cadastro.json, nfe_itens.json, vendas.json, contagens.json. O robô local pode alimentar os mesmos arquivos com pizzaria sincronizar-json.
